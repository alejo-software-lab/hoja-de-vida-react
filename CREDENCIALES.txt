================================================================================
ENDPOINTS API
================================================================================

POST   /api/contact              # Enviar formulario de contacto
GET    /api/contact/messages     # Listar todos los mensajes (admin)
GET    /api/contact/count        # Contar mensajes totales

Ejemplo Request (POST /api/contact):
{
  "name": "Juan Pérez",
  "email": "juan@ejemplo.com",
  "subject": "Consulta laboral",
  "message": "Hola, me interesa tu perfil..."
}

Ejemplo Response (éxito):
{
  "ok": true,
  "saved": true,
  "emailSent": true,
  "message": "Mensaje enviado correctamente"
}

Ejemplo Response (error validación):
{
  "ok": false,
  "saved": false,
  "emailSent": false,
  "error": "El email no es válido"
}

CONFIGURACIÓN (application.properties)
================================================================================

# Puerto del servidor
server.port=8080

# Base de datos H2 (desarrollo)
spring.datasource.url=jdbc:h2:mem:cvdb
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=
spring.h2.console.enabled=true
spring.h2.console.path=/h2-console

# JPA/Hibernate
spring.jpa.database-platform=org.hibernate.dialect.H2Dialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

# CONFIGURACIÓN EMAIL (CREDENCIALES - CONFIGURAR EN PRODUCCIÓN)
# ============================================================
spring.mail.host=${SMTP_HOST:smtp.gmail.com}
spring.mail.port=${SMTP_PORT:587}
spring.mail.username=${SMTP_USER:TU_EMAIL@gmail.com}
spring.mail.password=${SMTP_PASS:TU_APP_PASSWORD}
spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true

# Email remitente/destinatario
app.mail.from=${MAIL_FROM:noreply@tudominio.com}
app.mail.to=${MAIL_TO:alejandromg94@outlook.com}

# CORS (frontend React en puerto 5173)
app.cors.allowed-origins=http://localhost:5173,http://localhost:3000

CÓMO EJECUTAR EL BACKEND
================================================================================

OPCIÓN 1: Maven Wrapper (recomendado)
-------------------------------------
cd hoja-de-vida-react
./mvnw spring-boot:run

OPCIÓN 2: Maven instalado globalmente
-------------------------------------
cd hoja-de-vida-react
mvn spring-boot:run

OPCIÓN 3: JAR ejecutable (producción)
-------------------------------------
cd hoja-de-vida-react
mvn clean package
java -jar target/hoja-de-vida-backend-1.0.0.jar

El backend estará en: http://localhost:8080
H2 Console: http://localhost:8080/h2-console
  JDBC URL: jdbc:h2:mem:cvdb
  User: sa
  Password: (vacío)

DESPLIEGUE EN PRODUCCIÓN
